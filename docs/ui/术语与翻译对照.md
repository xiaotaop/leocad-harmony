# 术语与翻译对照

> 负责人：成员 C　适用范围：`resources/leocad_zh_CN.ts`、分类名、颜色名、界面文案

## 1. 翻译原则

1. **存储值不翻译，只翻译显示值。** 分类名与颜色名以英文存进设置文件和
   LDraw 配置；翻译只发生在放进 `QString` 显示之前。
   原因见 `docs/release/已知问题.md` 与 `common/lc_colors.h` 的注释。
2. **术语一致优先于"更好听的译法"。** 同一英文词在全文只用一个中文词。
3. **允许保留英文的场景**：产品名（LeoCAD、LDraw、LEGO、Blender、POV-Ray、BrickLink）、
   单位（LDU、mm、cm）、纯符号（`%1`、`&`、`...`）。
4. **不出现乱码、截断、不可读文本**（分工文档 §1.1）。颜色名与分类名走
   `QString` 显示层，因此不受 `char[64]` 缓冲限制。

## 5. 维护流程

```bash
source .devtools/env.sh
lupdate common qt -no-obsolete -locations none -ts resources/leocad_zh_CN.ts
python3 scripts/l10n/fill_zh_cn.py                # 补齐已知译文
lrelease resources/leocad_zh_CN.ts -qm resources/leocad_zh_CN.qm
python3 scripts/l10n/check_translations.py        # 门禁
```

`fill_zh_cn.py` 只填空缺，不覆盖已有的正确译文，因此可以反复运行。

**注意**：不要用 `lupdate leocad.pro`——它会同时重写全部 8 个语言文件，
把无关改动带进 PR。始终用 `-ts resources/leocad_zh_CN.ts` 指定目标。
`check_translations.py` 会拒绝：必需 context 存在未译串、译文为空、
复数条目缺 `<numerusform>`、文件带 BOM 或 CRLF。
