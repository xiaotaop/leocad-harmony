## 2. 本轮修掉的真实缺陷

不是文档润色，是**材料与仓库事实矛盾**的地方。每条都有可复核的依据。

### 2.1 隐私承诺有两处真实违规（最严重）

`docs/release/隐私政策.md` §2 承诺"不打开外部网址"。这条承诺此前只在**菜单命令层面**被守住
（`ApplyFirstReleaseScope()` 移除 `LC_HELP_HOMEPAGE`/`LC_HELP_BUG_REPORT`）。但另有两条路径
**不经过任何命令**，直接在 `.ui` 里开着 `openExternalLinks=true`：

| # | 位置 | 可达路径 | 处置 |
|---|---|---|---|
| 1 | `common/lc_aboutdialog.ui:59-62` | 帮助 → 关于（`LC_HELP_ABOUT` **不在**裁剪列表，`lc_mainwindow.cpp:633` 仍加入菜单） | 改为纯文本，`openExternalLinks` = false |
| 2 | `common/lc_setsdatabasedialog.ui:76` | 零件面板右键 → 编辑调色板 → 导入（`lc_partselectionwidget.cpp:1290` → `ImportButtonClicked()` → `lcSetsDatabaseDialog`） | 同上 |

第 2 条是**审计时没有发现的**：原计划只知道 About 一处。它比 About 更难发现，因为它藏在两级对话框之后。
两处的网络层其实都已被 `LC_DISABLE_NETWORK` 桩掉（`lcHttpManager::DownloadFile` 直接返回 error），
**唯一真实发生的是"点击拉起浏览器"**——但那已经足够让隐私政策那句话变成不实陈述。

处置原则：**保留地址文本、可选中复制，只是不再可点击。** 不删除信息，也不新增对外链接。

## 3. 新增的两道自动检查

发布材料此前是"写给人看、没人守"的文档。D11 把其中可机械判定的部分变成 CI 项。

### 3.1 `scripts/library/test_release_materials.py`（4 项）

| 检查 | 守什么 |
|---|---|
| 图标哈希 | `图标冻结.md` 表格里每一行的字节数与 SHA-256 必须等于磁盘文件；反向：`tools/icon` 下有文件却没进表格也失败 |
| 商店身份 | 文案必须出现 `CMakeLists.txt` 实际设置的 `APP_NAME` / `VERSION_NAME` / `BUNDLE_NAME` |
| 许可解释 | 不得出现"可以作为 or later / 补写 or later"等被禁路径；且必须保留"不把…"的拒绝理由 |
| 重新生成的承诺 | 若材料提到三个不存在的脚本，同段落必须写明"不存在" |

**变异验证（4/4 捕获）**：改一个图标字节、把应用名改错、追加 "or later" 建议、声称脚本可重建——
各自都让脚本非零退出，还原后恢复通过。

### 3.2 `scripts/library/verify_sample_model.py`（3 项）

校验截图用样例模型 `docs/evidence/member-c/2026-11-06/screenshot-sample.ldr`：
引用的每个零件 ID 必须在 `assets/ldraw-lite/library-lite.zip` 内，每个颜色码必须在 `ldconfig.ldr` 内。
**变异验证（2/2 捕获）**：改一个零件 ID 为 30011、改一个色码为 999，均失败。
这条检查防的是"样例模型用了完整 LDraw 有、精简库没有的零件，真机上渲染成占位盒"。

### 3.3 `test_network_scope.py` 从 10 项扩到 13 项

新增两项守 §2.1 的修复：扫描**全部** `.ui`，任何开启 `openExternalLinks` 的 label 都失败；
唯一例外是不可达的 `lc_updatedialog.ui`，而**该例外成立的两个前提本身也被断言**
（`LC_HELP_UPDATES` 仍在裁剪列表、`lcDoInitialUpdateCheck()` 仍在 `#if !LC_DISABLE_UPDATE_CHECK` 内），
任一失效先报错，例外不会悄悄过期。第三项断言隐私政策仍描述这条机制。

**变异验证（1/1 捕获）**：把 About 改回可点击，脚本失败并指名 `common/lc_aboutdialog.ui`。

本轮**没有**修改：`COPYING`（不重写许可授权）、`common/` 以外任何源码、`tests/`、`module.json5`、
`lc_mainwindow.*`、零件库内容或其清单。

若组长认为 About 归平台侧，这两处可单独拆出转交，检查脚本不受影响。

1. **截图一张都没有。** 本轮只冻结方案与样例模型。这是设计如此，不是遗漏。

4. **信号：材料齐备 ≠ 可提交。** 方案文档 §9.3 的放行条件七条里，材料侧只解决了第 4、6 条的"有"，
   第 5、7 条仍阻断。
