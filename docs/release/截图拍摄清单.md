## 3. 六张逐条清单

每张都写：**必须出现的元素**（拍完自查）与**这张不能用的情况**。

### 01 主界面全貌 — `leocad-harmony-<版本>-01-main.png`

- 必现：中文菜单栏、零件面板、3D 视图、已加载的示例模型、状态栏
- 不能用：模型是空场景；界面是英文；出现任何个人目录路径
- 建议：先打开示例模型并执行"适应窗口"，让模型完整可见

### 02 零件面板 — `...-02-parts.png`

- 必现：分类树（含展开状态）、零件缩略图清晰可辨、搜索框内是占位提示词（不是已输入内容）
- 不能用：缩略图糊成一格灰块（高分屏 DPR 未生效）

### 03 颜色面板 — `...-03-colors.png`

- 必现：颜色分组（实色/半透明/特殊）、中文颜色名
- 不能用：颜色全是色块没有名称；出现英文颜色名

### 04 建模中 — `...-04-editing.png`

- 必现：已选中某个零件（有高亮）、属性/坐标面板显示该零件的数值
- 不能用：只是主界面换个角度，没有任何选中态

### 05 搜索 — `...-05-search.png`

- 必现：搜索框内有关键词、结果列表已过滤、结果数量明显少于全量
- 不能用：搜索框空着；结果与 02 完全一样

### 06 保存/打开 — `...-06-filepicker.png`

- 必现：系统文件选择器、**路径栏不暴露个人目录名**
- 不能用：画面里有用户名、主机名、个人文档名
- 建议：提前把示例模型放在一个中性目录（如 `Documents/models/`）再打开选择器
