## 5. 必须上报组长的阻断项

### 5.1 【P0】更新检查在鸿蒙构建下可能尝试联网

| 项 | 内容 |
|---|---|
| 现象 | `qt/qtmain.cpp:222` 在 `#if !LC_DISABLE_UPDATE_CHECK` 下调用 `lcDoInitialUpdateCheck()`，后者请求 `https://www.leocad.org/updates.txt` |
| 根因 | `LC_DISABLE_UPDATE_CHECK` 当前**只在 `leocad.pro` 的 `macx` 段定义**（第 166 行） |
| 后果 | 若鸿蒙构建未定义该宏：首次启动弹"正在连接更新服务器…"，违反"不申请网络权限"，且无网络时报错 |
| 影响 | 违反 `docs/release/隐私政策.md` §2 与 `docs/release/权限说明.md` §1 |
| 要求 | 鸿蒙构建必须定义 `LC_DISABLE_UPDATE_CHECK=1`（组长负责 `leocad.pro` / CMake） |
| 成员 C 已做的缓解 | `ApplyFirstReleaseScope()` 已从帮助菜单移除"检查更新"，用户无法手动触发；但**自动检查仍需宏关闭** |
| 锁定测试 | `tests/library/test_ui_scope.py::NetworkScopeTests`（当前 skip，宏补上后自动转为强断言） |

## 7. 已知的环境约束（开发期）

| 项 | 说明 |
|---|---|
| 本机无 Qt / cmake / uic / moc / rcc | 已用 `scripts/dev/install-qt-desktop.sh` 装到 `.devtools/`（不入库） |
| 本机内存 7 GB | 并行编译需限制任务数；`build-desktop.sh` 默认 `JOBS=4`，32 并发会触发换页导致编译器长时间无响应 |
| WSLg 截屏受限 | `xwd -root` 对 WSLg 根窗口报 `BadMatch`；界面验证以启动稳定性 + 离屏渲染为主 |
| `libGL.so` 需手工补链 | `libgl-dev` 只装符号链接，目标库不在 sysroot；安装脚本已自动修复 |
