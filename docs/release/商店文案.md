> 完全离线，无需联网。

## 4. 详细描述

> **用虚拟积木，搭出真实的想法**
>
> 积木立构让你在鸿蒙 PC 上像搭真实积木一样建模。内置离线 LDraw 零件库，
> 按类别浏览或直接搜索，选好颜色就能开搭。
>
> 内置库是 **1160 件精选零件**（含 669 个子部件与 911 个图元，共 2741 个文件），
> 覆盖常见建模需要；它是完整 LDraw 官方库的精简子集，**不是完整库**。
>
> **核心功能**
> - 按分类浏览与关键词搜索零件，支持颜色预览
> - 插入、选择、移动、旋转、删除零件
> - 为零件修改颜色
> - 鼠标完成视图旋转、平移、缩放与适应窗口
> - 撤销与重做，放心试错
> - 打开与保存 `.ldr`、`.mpd` 模型文件
>
> **为鸿蒙 PC 优化**
> - 原生界面，中文优先
> - 支持高分屏与窗口缩放
> - 鼠标与物理键盘操作
>
> **完全离线**
> 不需要网络，不收集个人信息，不申请网络权限。你的模型只保存在自己的设备上。
>
> **关于 LeoCAD**
> 本应用是开源项目 LeoCAD 的鸿蒙 PC 社区移植版，基于 LDraw 零件标准。
> LeoCAD 由 LeoCAD.org 开发，本应用非官方发布版本，与上游项目无隶属关系。
> LEGO 是 LEGO Group 的商标，LEGO Group 未赞助、授权或认可本项目。

### 7.1.1 示例模型（为了让 01 / 04 号截图可复现）

截图不应该靠临场在设备上现搭一个模型——那样每次拍都不一样，也无法回头重拍同一张。
因此 D11 随材料提交了一个固定样例：`docs/evidence/member-c/2026-11-06/screenshot-sample.ldr`。

| 项 | 说明 |
|---|---|
| 用途 | 01 号（主界面全貌）与 04 号（建模中）的场景模型 |
| 内容 | 一栋小房子：8×8 底板 + 两层墙 + 屋顶 + 烟囱，用 3003/3004/3035 等**精简库内真实存在**的零件 |
| 颜色 | 均为 `ldconfig.ldr` 已定义的色码（淡蓝灰 71 底板、红 4 一层墙、黄 14 二层墙、深红 320 屋顶、棕 19 烟囱） |
| 编辑方式 | 可在应用内直接打开、旋转到合适角度后拍摄；不要在截图前改模型结构 |
| 如何验证 | `python3 scripts/library/verify_sample_model.py`（5 项）：**逐条**解析每个型号 1 行（无法解析即失败，不跳过）、零件 ID 在 `library-lite.zip` 内、颜色码在 `ldconfig.ldr` 内，并按零件**真实几何**校验竖直堆叠是否连续。已接入 CI（port-policy job） |
| 它不保证什么 | 不保证模型好看，也不保证真机渲染效果——后者仍需组长在 RC1 真机上确认 |
| 版权 | 自行搭建，不复用任何受保护的作品设计（§7.1 "内容"行） |
| 竖直方向 | LDraw 的 Y 轴**向下**：零件原点在顶面，本体占正 y，LeoCAD 转换后保持该方向（`common/lc_math.h` 的 (x,y,z)→(x,z,-y)）。因此**往上堆就是 y 递减**。本样例的层叠高度均由零件真实尺寸算出，并由检查脚本验证堆叠连续 |

### 7.3 格式与命名

| 项 | 规定 | 理由 |
|---|---|---|
| 采集格式 | PNG，**设备原生分辨率**整屏采集（等同系统截图） | 二次压缩的 JPEG 会把细线和小字号糊掉，而首发版的卖点之一是界面清晰度 |
| 不缩放、不裁剪 | 原图直接用；若市场有尺寸上限，从原图**另存**一份并记录缩放命令与工具 | 任何缩放都会让"截图是不是这台设备拍的"变得不可核对 |
| 不后期 | 不做锐化、加边框、加文案、加箭头、加水印 | 视觉修饰一旦进图，画面就不再是包内真实渲染 |
| 色彩 | 保持设备原色，不做色彩管理转换 | — |
| 文件命名 | `leocad-harmony-<版本>-<两位序号>-<场景>.png`，例：`leocad-harmony-0.1.0-01-main.png` | 序号与 §7.2 编号一致，市场端上传顺序可对回本表 |
| 存放 | 统一放 `docs/evidence/leader/<日期>/store-shots/`，同目录附 `manifest.json` | 与已有真机证据同一套归档习惯 |
| 清单内容 | 每张图记录：文件名、像素尺寸、字节数、SHA-256、采集设备、系统版本、DPR、所用 HAP 的 SHA-256 | 截图是提交材料，必须能回溯到具体那个包 |

文件名与清单里**不得出现** `/home/<用户名>`、`C:\\Users\\...` 这类路径，也不得出现设备序列号。

上游 LeoCAD 声明为 GPL **第 2 版**，鸿蒙版链接的 Qt 6 是 LGPL-3.0 / GPL-3.0 双授权，两者存在版本兼容性议题
（`docs/release/第三方组件清单.md` §5.1）。**在组长／法务给出裁定之前：**

- 本文件任何位置都**不写**"本应用以 GPL-2.0 发布""许可合规已满足"这类结论；
- 商店表单的许可证字段、详细描述里的许可句、包内 About/NOTICE 的措辞，统一以裁定结果为准；
- 若裁定为"需按 GPL-2.0-only 处置"，则当前分发形式本身需要重新评估，文案问题退居其次。

这条不是措辞偏好：写错了是许可声明失实，比"没写"更糟。
