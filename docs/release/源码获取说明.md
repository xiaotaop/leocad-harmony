> 负责人：成员 C　性质：GPL-2.0 分发义务的落实说明
> 状态：初稿，仓库地址与标签待组长补全

## 1. 法律依据

本应用包含 LeoCAD 的修改版本，以 GNU General Public License version 2 发布。
GPLv2 要求任何分发二进制的一方同时提供：

1. 许可证全文（GPLv2 正文）；
2. 版权声明；
3. **对应的完整源码**，或有效的书面获取方式。

本项目同时包含 LDraw 零件库子集（CC BY 4.0），该部分只需署名，不要求提供源码。

## 5. 可复现构建

外部第三方应能仅凭公开仓库重建同等功能的二进制：

1. 按 `toolchain.lock` 安装指定的 DevEco Studio、HarmonyOS SDK/NDK、
   Qt 6.12 for HarmonyOS、Clang、CMake；
2. 按 `docs/` 的构建说明生成 HAP/APP；
3. 零件库可用 `scripts/library/` 的脚本从官方库重建，
   并通过 `manifest.json` 的哈希核对一致性。

> `toolchain.lock` 当前为模板（`toolchain.lock.example`），
> 需组长在 D1 填入真实版本后，本文件才能声称完整可复现。
