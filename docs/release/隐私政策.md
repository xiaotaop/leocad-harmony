# 隐私政策

> 适用应用：LeoCAD（鸿蒙 PC 首发版）　负责人：成员 C
> 状态：初稿。§4 已按打包产物的实际 6 项权限逐项核对（2026-11-05）；
> 正式签名包仍需在 RC0 上复核一次。

## 1. 核心结论

**本应用不收集、不上传、不共享任何个人信息。所有数据仅保存在您的设备本地。**

首发版本完全离线运行：不联网、不申请网络权限、无遥测、无广告、无第三方统计 SDK。

**这一结论的依据是功能裁剪，不是代码里没有网络代码。** LeoCAD 上游带有 `common/lc_http.cpp`
（Qt Network），用于下载 Blender 附加组件和 BrickLink 库存数据库。首发版把相关入口从菜单中移除
（`lcMainWindow::ApplyFirstReleaseScope()` 中的 `LC_FILE_RENDER_BLENDER`、
`LC_FILE_RENDER_OPEN_IN_BLENDER`、`LC_FILE_IMPORT_INVENTORY` 等），这些路径在界面上不可达，
因此不会发起请求。

需要留意：如果后续版本恢复这些功能，本节结论与「不申请 INTERNET 权限」必须同时复审——
权限说明里不申请网络权限是当前裁剪范围的产物，不是永久属性。

## 2. 我们不做什么

| 项 | 说明 |
|---|---|
| 不收集个人身份信息 | 不索取姓名、手机号、邮箱、位置、通讯录、相册、麦克风、摄像头 |
| 不上传模型文件 | 您创建的模型只保存在本机 |
| 不上传使用数据 | 无埋点、无崩溃上报、无行为统计 |
| 不含广告 | 无广告 SDK |
| 不含第三方追踪 | 无分析、归因或推送 SDK |
| 不发起网络请求 | 不检查更新、不下载零件、不访问在线资源 |

**本节三条承诺的依据**（便于复核，不是新增承诺）：

- **不检查更新**：鸿蒙构建用根 `CMakeLists.txt`（`scripts/build-harmony-app.ps1` 配置的就是它），
  第 75–82 行对 `leocad` 目标无条件定义 `LC_DISABLE_UPDATE_CHECK=1`，`qt/qtmain.cpp:308` 的启动
  更新检查因此不参与编译；OHOS 另定义 `LC_DISABLE_NETWORK=1` 编译关闭网络层。
  由 `scripts/library/test_network_scope.py` 锁定（删除任一定义即失败）。
- **不下载零件、不访问在线资源**：`lc_http.cpp` 的全部入口——Blender 附加组件下载、
  打开 Blender、下载库存——对应的三个命令 `LC_FILE_RENDER_BLENDER`、
  `LC_FILE_RENDER_OPEN_IN_BLENDER`、`LC_FILE_IMPORT_INVENTORY` 已由
  `ApplyFirstReleaseScope()` 从菜单移除，用户无法触达。同一测试文件锁定。
- **不打开外部网址**：帮助菜单的「主页」与「报告问题」会调用
  `QDesktopServices::openUrl` 打开 `https://www.leocad.org/` 和 GitHub issues。这两个不属于
  `lc_http`，`LC_DISABLE_NETWORK` 拦不住（那是 Qt GUI，不是 Qt Network）——应用自身不发请求，
  但它会拉起浏览器去访问，同样违反本节承诺。**D8 界面冻结时发现二者此前无任何拦截**，现已加入
  `ApplyFirstReleaseScope()` 的移除列表，并由静态检查（校验裁剪列表条目数与
  `lc_mainwindow.cpp` 中 `openUrl(http…)` 调用点数量一致）和窗口级菜单测试双重锁定。
  同一轮核对还发现**两处不经过菜单命令、直接写在 `.ui` 文件里的可点击链接**：「关于」对话框的
  `https://www.leocad.org`，以及零件面板「编辑调色板 → 导入」可达的套件数据库对话框里的
  Rebrickable 链接——两者的 label 都开着 `openExternalLinks`，裁剪列表对它们无效，因为没有命令可删。
  D11 已把两处改为纯文本（地址仍可见、可选中复制，点击不再拉起浏览器），并新增静态检查扫描全部
  `.ui`：任何开启 `openExternalLinks` 的 label 都会失败；唯一例外是不可达的更新对话框，
  而它不可达的两个前提（`LC_HELP_UPDATES` 在裁剪列表、`lcDoInitialUpdateCheck()` 在
  `#if !LC_DISABLE_UPDATE_CHECK` 内）本身也被断言，任一失效先失败。
- **不申请网络权限**：见 `权限说明.md` §6；该条已在 2026-11-02 的打包产物中直接核对
  （`grep -c ohos.permission.INTERNET` = 0），正式签名包仍需 RC0 复核。

## 3. 我们在本机保存什么

应用在系统为本应用分配的沙箱目录内保存以下内容，**不会离开设备**：

| 内容 | 位置 | 用途 | 可否删除 |
|---|---|---|---|
| 您创建的模型（`.ldr` / `.mpd`） | 您选择的保存位置 | 您的工作成果 | 可，由您自行删除 |
| 应用偏好设置（语言、主题、窗口布局、快捷键） | 应用设置目录 | 记住您的使用习惯 | 可，卸载即清除 |
| 零件库索引缓存 | 应用缓存目录 | 加速零件面板首次打开 | 可，删除后自动重建 |
| 最近文件列表 | 应用设置目录 | 方便再次打开 | 可，卸载即清除 |

**不保存**：任何账号信息、设备标识符、IP 地址、位置、使用时长统计。

## 4. 我们申请哪些权限

2026-11-05 留存的打包产物声明以下 6 项权限，与 [权限说明.md](./权限说明.md) §1 对应。正式发布包的权限及用途需在发布前重新核对。

| 权限 | 用途 | 是否读取您的数据 |
|---|---|---|
| `ohos.permission.FILE_ACCESS_PERSIST` | 在您自己选择的位置打开和保存模型文件 | 只读写您主动选择的文件 |
| `ohos.permission.STORE_PERSISTENT_DATA` | 当前包声明；偏好设置在应用沙箱保存，是否依赖该权限待核验 | 权限在 Qt 运行时的具体使用待核验 |
| `ohos.permission.READ_PASTEBOARD` | 支持零件复制粘贴并更新粘贴菜单状态 | 窗口创建及剪贴板变化时查询 MIME 信息；有 LeoCAD 格式时读取该格式内容，读取受系统授权约束 |
| `ohos.permission.PREPARE_APP_TERMINATE` | 当前包声明；Qt 运行时的退出处理与权限依赖待核验 | 具体调用及数据访问范围待核验 |
| `ohos.permission.GET_FILE_ICON` | 本仓库未发现直接调用；已列为候选移除项 | Qt 后端的实际使用待核验 |
| `ohos.permission.PRINT` | 应用打印入口已移除；包仍声明，已列为候选移除项 | Qt PrintSupport 的实际使用待核验 |

**明确不申请**：网络（`INTERNET` / `GET_NETWORK_INFO`）、位置、相机、麦克风、通讯录、
相册、日历、短信、后台运行、开机自启。详见 [权限说明.md](./权限说明.md) §6。

候选移除项需经 Qt 后端核对和新包回归后确定。上表保留待核验状态，发布前应填写最终权限用途与数据范围（见 `权限说明.md` §4）。剪贴板读取时机依据 `common/lc_mainwindow.cpp` 的构造函数和 `ClipboardChanged()`。

## 5. 未成年人

本应用不收集任何个人信息，因此不涉及未成年人个人信息处理。
应用内容为通用建模工具，无社交、无用户生成内容上传。

## 6. 数据删除

- 删除单个模型：在应用内或通过系统文件管理器删除对应文件。
- 清除全部应用数据：卸载应用，或在系统"应用管理"中清除本应用数据。
- 无云端副本，因此删除即为彻底删除。

## 7. 开源与第三方

本应用基于开源项目 LeoCAD（GPL-2.0），并随包分发 LDraw 零件库子集（CC BY 4.0）。
详见 `docs/release/第三方组件清单.md` 与 `docs/library/D2_精简零件库与资源部署方案.md`。
这些组件**不包含**数据收集功能。

## 8. 政策变更

若后续版本新增联网功能（在线零件库、更新检查、云同步等），我们会在发布前更新本政策，
并在应用内或商店更新说明中明确告知。
