# 权限说明

> 负责人：成员 C　配套：`docs/release/隐私政策.md`
> 目标：**只申请必要权限，不申请网络权限**

## 1. 结论

| 能力 / 权限 | 是否申请 | 依据 |
|---|---|---|
| `ohos.permission.INTERNET` | **不申请** | 首发版全部功能离线可用；联网入口（Blender 附加组件、BrickLink 库存下载）已被 `ApplyFirstReleaseScope()` 从菜单移除 |
| 文件选择（系统 Picker） | 使用，非敏感权限 | 打开/保存模型必需 |
| 读取用户选择的文件 | 使用（仅限用户选择结果） | 打开 `.ldr` / `.mpd` |
| 写入用户选择的位置 | 使用（仅限用户选择结果） | 保存模型 |
| 应用沙箱内读写 | 使用（应用自有目录，无需额外权限） | 设置、缓存、零件库 |
| 位置 / 相机 / 麦克风 / 通讯录 / 相册 / 日历 / 短信 | **不申请** | 与功能无关 |
| 后台运行 | **不申请** | 前台建模工具 |
| 开机自启 | **不申请** | — |

> **结论的时效性：** 「不申请网络权限」是当前功能裁剪的结果。上游代码含 `common/lc_http.cpp`
> （Qt Network），若后续版本恢复上述联网入口，必须同时重新申请并复审隐私政策第 1 节，
> 不能沿用本文档的结论。

## 2. 逐项说明

### 2.1 文件选择

- **何时触发**：用户主动点击"文件 → 打开""文件 → 保存""文件 → 另存为"。
- **做什么**：调用系统文件选择器，由系统 UI 让用户选定文件；应用只拿到用户
  明确选择的那个路径。
- **不做什么**：不遍历目录、不扫描存储、不在后台访问文件、不读取用户未选择的文件。
- **取消行为**：用户取消选择时，应用保持当前模型不变，不报错。
- **分工文档依据**：§8「文件选择 → 模型层：平台层返回可读/可写的本地路径或明确的
  取消/失败状态」。

### 2.2 应用沙箱目录

应用在系统分配的沙箱内使用三个目录，不需要任何权限：

| 目录 | 内容 | 清理方式 |
|---|---|---|
| 应用数据目录 | 偏好设置、零件库副本 | 清除应用数据 |
| 应用缓存目录 | 零件索引缓存 | 系统可回收，应用可重建 |
| 临时目录 | 保存时的临时文件 | 保存成功后替换，失败则清理 |

`lcPiecesLibrary::FindBundledLibraryArchive()` 优先使用应用数据目录中的
`ldraw-lite/library-lite.zip`；该副本由平台层在首次运行时展开。

### 2.3 网络：明确不申请

首发版无联网功能，因此**不在 `module.json5` 中声明 INTERNET 权限**。
这样即使用户设备无网络，也不会出现任何联网相关错误提示。

**必须由组长在构建层确认的事项**（见 §3 风险）：上游代码默认会在启动时检查更新，
需通过编译宏关闭。

## 3. 风险与必须上报的事项

### 3.1 【P0，需组长处理】更新检查会尝试联网

| 事实 | 位置 |
|---|---|
| 启动时调用 `lcDoInitialUpdateCheck()` | `qt/qtmain.cpp:222`，受 `#if !LC_DISABLE_UPDATE_CHECK` 包裹 |
| 该函数创建 `lcUpdateDialog` 并请求 `https://www.leocad.org/updates.txt` | `common/lc_updatedialog.cpp:42` |
| `LC_DISABLE_UPDATE_CHECK` 目前**只在 macOS 构建中定义** | `leocad.pro:166`（`macx` 段内） |
| 鸿蒙构建若未定义该宏，首次启动会弹出"正在连接更新服务器…" | 实测代码路径 |

**后果**：违反"不申请网络权限"，且无网络时会产生联网错误提示，
与 `docs/release/隐私政策.md` §2 的承诺矛盾。

**要求**：鸿蒙构建必须定义 `LC_DISABLE_UPDATE_CHECK=1`。这属组长的构建配置范围
（`leocad.pro` / CMake），成员 C 不直接修改，只在此记录并已提交建议。

**成员 C 一侧的补充保险**：`ApplyFirstReleaseScope()` 已把 `LC_HELP_UPDATES`
从帮助菜单移除，因此即使宏漏定义，用户也无法从界面发起更新检查——
但**启动时的自动检查仍需宏来关闭**，两者不能互相替代。

## 4. 与隐私政策的一致性核对

| 隐私政策声明 | 代码/配置依据 | 一致 |
|---|---|---|
| 不联网 | 不申请 INTERNET；`LC_DISABLE_UPDATE_CHECK=1`（待组长确认） | 待确认 |
| 无遥测/统计 | 无相关 SDK，`grep` 无分析代码 | 一致 |
| 不上传模型 | 无上传路径 | 一致 |
| 仅读写用户选择的文件 | `QFileDialog` 路径，无目录扫描 | 一致 |
| 数据仅在本地 | 沙箱目录 | 一致 |

## 5. 上架时填写的权限描述（草稿）

供应用市场"权限说明"字段使用：

> 本应用不需要网络权限，全部功能离线使用。
> 文件访问权限仅用于打开和保存您主动选择的模型文件，应用不会扫描或上传您的文件。
> 应用不收集任何个人信息。
