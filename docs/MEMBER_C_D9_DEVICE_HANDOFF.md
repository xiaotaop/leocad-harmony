# 成员 C D9：真机核对清单

D9 的修复与结论全部来自桌面（Linux/WSL + `QT_QPA_PLATFORM=offscreen`）。本清单列出**只能在鸿蒙 PC 真机上判定**的项目，以及每项的具体判据。

沿用 D8 的做法：[MEMBER_C_D8_DEVICE_HANDOFF.md](./MEMBER_C_D8_DEVICE_HANDOFF.md) 里的项目若本轮未变，不重复列。

## 1. 空 Time 工具栏是否真的消失了（本轮修复）

**判据**：启动进入主界面，视口上方不应出现一条没有任何按钮的空白带。

**背景**：修复前 Time 工具栏被首发范围裁空但仍在布局里占一行（宿主实测 473×39）。修复后它被隐藏，View ▸ Toolbars 里的对应复选项也一并消失。

**要看的点**：
- 视口上方是否还有空白带；
- View ▸ Toolbars 里是否**没有** "Time" 这一项；
- 在标题栏右键弹出的工具栏菜单里同样没有 "Time"；
- Standard、Tools 两个工具栏位置与内容不变。

**若仍有空白带**，说明 `restoreState()` 之后那次清扫没生效或真机走的是另一条路径，请附截图与 `/data/app/el2/.../preferences` 下的配置。

## 2. 布局密度与最小窗口尺寸

**判据**：窗口缩到最小、以及 1280×800 / 1920×1080 两档 DPI 下，菜单栏、工具栏、三个停靠面板、状态栏不重叠、不裁字、不出现滚动条遮挡。

**背景**：D9 的布局修复只涉及工具栏占位，没动任何尺寸常量。但首发范围裁掉了大量命令，菜单项变少后各菜单宽度变化，理论上可能出现异常窄的菜单。offscreen 下量不出真实字体宽度。

## 3. 字体：字形覆盖与回退（D8 项目 5 的复验）

**判据**：中文菜单、中文提示、零件分类名与颜色名无缺字方框；英文零件名与中文混排时不出现基线错位。

**背景**：本轮**没有**对字体做任何改动，也没有新的字体结论。offscreen 平台无真实字体栈，字体度量测不出来。此项仍是 D7 真机探针的延续，不因本轮"全绿"而视为已验收。

## 4. 焦点链

**判据**：Tab 顺序在零件面板 → 视口 → 时间轴 → 颜色面板之间合理；对话框弹出与关闭后焦点回到原控件；快捷键在无鼠标操作时可用。

**背景**：offscreen 下没有真实焦点窗口，本轮无法验证。D9 任务行里的"焦点"一项，宿主侧只能到此为止。

## 5. 菜单分隔线（本轮确认不是缺陷）

**判据**：File / View / Help 菜单里不应出现**连续两条**分隔线，Help 菜单开头不应有分隔线。

**背景**：`QMenu::actions()` 里能看到这些多余条目，但 Qt 的 `separatorsCollapsible` 默认为 true，绘制时会把相邻分隔线合并、把前导分隔线折叠成 0×0。宿主几何探针实测"实际绘制 0 条"。若真机上**看到**了双分隔线，说明该平台的样式表或 `separatorsCollapsible` 被改过——那是新信息，请按缺陷上报。

## 6. 裁剪后的命令是否真的不可达（键盘路径）

**判据**：按 `Ctrl+F`（查找）、`Ctrl+P`（打印）等已裁剪命令的快捷键，不应有任何反应。

**背景**：宿主实测隐藏动作的快捷键不触发（`hidden+enabled fired: 0`）。真机上若被触发，属于平台差异，需按缺陷处理。

## 7. 取证建议

每项至少一张截图；涉及"没有反应"的项目（1、5、6）请附**操作视频或连续截图**，单张静态图无法证明"没有发生"。

## 8. 边界声明

本清单中任何一项在真机上未通过，都构成首发阻断，需回到代码侧处理。本成员未做任何真机结论，本文所有判据均为待验证状态。
