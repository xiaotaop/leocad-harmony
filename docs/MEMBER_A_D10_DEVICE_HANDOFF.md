# D10 渲染性能与 #45 真机交接

请按 20:30 前交接、21:00 批次安排，在包含本 PR 的集成提交上出 Release 签名 HAP。收据记录实际 Git SHA、包 SHA-256、native Build ID、渲染模式、显示档位、DPR、应用 PID 和时间。主测使用正常模式。若出现黑屏或显示异常，可用基础模式复跑对照，单独记录包身份和结果。

1. 启动新包，记录从点击图标到主窗口可交互的时间和初始内存。确认 `LEOCAD_GL_RENDERER` 正常，零件面板可见。
2. 同一 PID 连续三轮从系统选择器打开 D8 LDR，再打开 `curated-device.mpd`。每轮完成选择、Right、Ctrl+Z/Y、菜单和子模型切换。记录每轮 PID、时间、操作结果和实际缩略图。
3. 至少一轮切换零件面板显示状态，再恢复面板并执行分类和搜索。确认视口、面板和实际缩略图都能更新。若有持续空图或界面阻塞，记录准确时间、可见零件和窗口状态。
4. 通过系统选择器打开[固定中型 MPD](evidence/member-a/2026-11-05/d10-2000.mpd)。记录选择器返回到模型首帧的时间。确认主模型含 4 个子模型，每个有 500 个实例，视口完整且可操作。
5. 在主模型和子模型中连续旋转、平移、缩放、选择和移动零件，执行撤销与重做。记录是否出现操作超过一秒未响应、持续掉帧或错误拾取。可获得帧时数据时记录中位数与慢帧，注明采集方式。
6. 最小化/恢复和调整窗口大小，再次检查模型、菜单与缩略图。记录实际分辨率和 DPR。30 分钟内每 5 分钟重复一轮导航与编辑，保留开始、模型加载后、15 分钟和 30 分钟的同 PID 内存样本。
7. 中文路径另存，正常退出，二次启动并通过选择器重开。核对选定编辑、颜色、子模型和实例数，保留保存与重开文件。
8. 汇总 `LEOCAD_GL_CONTEXT`、`LEOCAD_GL_FRAMEBUFFER`、`LEOCAD_THUMBNAIL_DEFERRED`、watchdog/崩溃、正常退出日志和失败轮次时间线。若出现卡死，先采集该 PID 的 Qt 主线程和加载线程栈，再退出。若测试包可设置 `LEOCAD_PERF_TRACE=1`，补充 `LEOCAD_GL_UPLOAD` 的网格和字节记录。

中型样例验收目标为可打开、可交互、可保存重开，30 分钟内无卡死或崩溃，内存样本无持续增长。建议把首次模型画面超过 1 秒或操作超过 1 秒仍未响应列为需复核项。若有 `state 0 refs 0`、乱码零件名或无法确认恢复的缩略图，保留 #45 并附原始日志。#15 的真实拒绝授权与写失败恢复由独立用例覆盖。
