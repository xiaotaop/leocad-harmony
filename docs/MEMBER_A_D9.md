# 成员 A D9：缩略图加载卡死防护与引用修正

## 修复

生产修改仅 `lc_thumbnailmanager.cpp`：

- 共享相同缩略图请求时增加已有ReferenceCount，使每个请求对应一次释放。原实现第二个请求没有计数，首个调用者释放就会删掉仍被其他调用者使用的条目。
- 绘制前确认当前零件已Loaded。陈旧完成通知到达时，如当前加载尚未完成，保留待处理条目及零件引用，等当前加载的完成通知再次生成；避免在GUI回调中创建同步等待的预览件。已有Pixmap不重复生成。
- 生成结果仍为空时保留待处理引用，避免随后取消/析构再次释放同一个引用。成功生成才释放这项待处理加载引用。
- 延迟路径记录 `LEOCAD_THUMBNAIL_DEFERRED`、零件名、state和refs，供新包回传核对。

没有把底层加载改成超时后继续绘制未加载零件；当前加载完成后仍必须生成真实非空缩略图。该防护与引用修正覆盖已取得的卡住调用链，但**尚未证明真机上产生陈旧通知/异常加载状态的完整生命周期根因，#45保持P1开放**；需以新包复验结果决定是否足以解除阻断。
