# 成员 A D6：鼠标导航、拾取与输入中断恢复

## 修正

1. 原 `SetFocus(false)` 不处理输入事务。原基线真实窗口负例中，旋转/平移/缩放通过，但 FocusOut、WindowDeactivate、Hide、UngrabMouse 四种中断后 `IsTracking()` 仍为 true。现在失焦取消待完成的移动等事务、结束活动平移手势，并清理视角球按下、修饰键及临时光标状态；未开始拖动时不会清空已有选择。普通视图相机保留最后显示的位置，未完成的模型移动回滚。
2. widget 记录本地接收的按键，忽略取消后的迟到释放，避免提交编辑或弹出右键菜单；移动事件发现按键已不再按下时也取消。普通鼠标离开画布不会主动取消仍被捕获的拖动。新按下时获取焦点并按当前坐标解析工具，焦点恢复后的首击不依赖先移动鼠标。框选缩放在 Accept=false 时不再执行缩放。
3. 平移手势有显式活动状态；失焦后的孤立 Update/End 不会继续平移或结束别的事务。新鼠标按下结束旧平移，新平移开始取消旧拖动。
4. DPR1 的 900×700 窗口测试暴露真实棱线漏选：点击 3003.dat 可见棱线时，原单精度包围盒中间量使另一轴交点落到边界外，网格相交测试被提前剔除。`lcBoundingBoxRayIntersectDistance` 的候选进入时间及交点中间计算改用 double，输入/输出仍为 float，原盒边界和射线语义不变。没有膨胀零件包围盒，也没有更改相机取景。
