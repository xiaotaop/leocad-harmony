# 成员 A D4：参考网格遮挡修正与实际 FBO 复验

构建源为本PR审核提交；先记录完整SHA、Qt/SDK和签名HAP哈希。正常模式明确
`LEOCAD_SAFE_RENDER=OFF`，不要只展示D3隐藏网格的基础包。本次未接触真机。

## 固定批次（9步）

1. 用已有 `scripts/build-harmony-app.ps1 -GenerateSignature` 流程构建正常包，记录提交和包哈希。
2. 冷启动，按既有沙箱/Want方式加载原样 `tests/fixtures/render-baseline.ldr`，记录PID；
   此路径不作为系统文件选择器通过证据。
3. 保持网格圆圈、线和原点轴开启，默认相机截图。预期网格周围可见，但不盖在红蓝实体表面；
   参考平面仍为Z=0，未改插入/拾取坐标。实体遮挡网格属于本次明确的参考背景策略。
4. 采集原始 `LEOCAD_GL_CONTEXT`、`LEOCAD_GL_RENDERER`、`LEOCAD_GL_FRAMEBUFFER`。
   正常shader为9/0；FBO实际绑定应等于qt_framebuffer、完整、depth≥16（该Kit预期24）。
   FBO日志在帧状态重置前采集，不凭其中Qt传入的depth_test=false直接判失败。
5. 放大/恢复窗口，每种尺寸截图；核对FBO日志的尺寸/DPR及depth未丢失。切前视/回主视再确认实体无遮挡。
6. 选中、取消选中积木并旋转相机，确认选择反馈正常；已有透明/贴图样例可追加验证，
   若没有样例则明确未测，不用选择半透明代替真实透明材料。
7. 正常关闭，再次启动并加载同一模型；记录新PID、日志和退出码，不以强停代替退出通过。
8. 如需对照基础模式，再装显式ON包确认网格仍隐藏；最后恢复OFF正常包。此步不能替代步骤3–7。
9. 回传提交/包哈希、原始hilog、各尺寸截图、PID和native main返回值；A核验后再决定关闭#12。

若FBO报告缺深度或绑定错误，保留原始日志，不把context.format的depth24当实际附件证明。
若新正常包仍覆盖网格，保留视角/尺寸/模型及完整图形日志，继续分析，不降低验收口径。
本次不覆盖休眠恢复、全量材质、系统选择器、长期稳定性或发布验收。

## 回退

撤回本PR可恢复旧网格顺序；旧问题会重现。紧急降级仍可使用D3的基础模式
`LEOCAD_SAFE_RENDER=ON`，必须明确标注“隐藏网格”，不能宣称已修正正常模式。
