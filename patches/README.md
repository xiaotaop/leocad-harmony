# Port patch records

Record port-specific changes by module:

- `platform/`: HarmonyOS application and Qt platform integration.
- `render/`: OpenGL, view and input compatibility.
- `model/`: editing and file behavior.
- `ui-library/`: widgets, resources and curated parts library.

Prefer normal Git commits for source changes. Use this directory for patch inventories, rationale and upstreamability notes rather than duplicating every commit as a patch file.
